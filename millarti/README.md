# Millarti — концепция

Самостоятельный статический сайт. Запуск из этой папки: `python3 -m http.server 8000`.

Направление деятельности и ссылки взяты из [публичного описания](https://github.com/ya-yura/millarti-krasnodar-landing-20260811). Указанные там первичные источники: [официальный сайт](https://millarti.ru/), [2ГИС](https://2gis.ru/krasnodar/firm/70000001052673664). Повторная прямая проверка из текущей среды недоступна. Цены, сроки и условия изготовления не заявлены.

Иллюстрация интерьера — оригинальная стилизация, не работа мастерской. Перед передачей сайту компании нужны сверка данных и согласование.
