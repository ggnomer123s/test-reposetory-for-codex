# Хинкали House — концепция

Самостоятельный статический сайт. Запуск из этой папки: `python3 -m http.server 8000`.

Данные об адресе и ссылки взяты из [публичного исследования](https://github.com/ya-yura/khinkali-house-site). Указанные там первичные источники: [официальный сайт](https://khinkali-house.ru/), [меню](https://menu.khinkali-house.ru/заказать-онлайн/), [2ГИС](https://2gis.ru/krasnodar/firm/3237490513542285). Повторная прямая проверка официального сайта и карточки из текущей среды недоступна. Режим, цены и наличие блюд на странице не утверждаются.

Иллюстрация — оригинальная стилизация блюда, не фото ресторана. Перед передачей сайту компании нужны сверка данных и согласование.
