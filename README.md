# Отдельные концепции сайтов

В репозитории лежат три **самостоятельных** статических сайта для разных организаций. У каждого свой HTML, CSS, локальные SVG-иллюстрации, favicon и workflow публикации. На сайтах нет ссылок друг на друга или на общий каталог. Корневая страница не публикует список организаций.

| Концепция | Папка | Публичный адрес текущего предпросмотра |
| --- | --- | --- |
| Хинкали House | [`khinkali-house/`](khinkali-house/) | `https://ggnomer123s.github.io/test-reposetory-for-codex/khinkali-house/` |
| Millarti | [`millarti/`](millarti/) | `https://ggnomer123s.github.io/test-reposetory-for-codex/millarti/` |
| Pinkme | [`pinkme/`](pinkme/) | `https://ggnomer123s.github.io/test-reposetory-for-codex/pinkme/` |

Для полностью отдельных адресов GitHub Pages понадобятся три отдельных репозитория или домена. Каждую папку можно перенести в корень собственного репозитория без правок путей. В настройках такого репозитория выберите Pages → Source → GitHub Actions; workflow уже находится внутри папки. Локально сайт открывается через `python3 -m http.server 8000` из его папки.

Иллюстрации созданы для этих макетов и не изображают реальный интерьер, блюдо или сотрудника организации. Макеты не согласованы с компаниями. Перед коммерческим использованием следует подтвердить сведения, ссылки и право публиковать сайт от имени компании.
