# Демонстрационные сайты для бизнеса Краснодара

Четыре статические страницы без сборки и зависимостей: каталог концепций и отдельные макеты для Хинкали House, Millarti и Pinkme. Запуск:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Ссылки на официальные каналы вынесены на страницы заведений. Факты, источники и ограничения проверки перечислены на странице «Исследование» (`research.html`).

Это независимые концепции. О наличии запроса на новый сайт от этих организаций сведений нет; у них уже есть публичные сайты или страницы. Перед использованием макета для реального бизнеса следует подтвердить актуальность информации и согласовать публикацию с владельцем. Иллюстрации выполнены средствами CSS, чужие фотографии и логотипы не использованы.
