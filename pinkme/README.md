# Pinkme — концепция

Самостоятельный статический сайт. Запуск из этой папки: `python3 -m http.server 8000`.

Направления деятельности и ссылки взяты из [публичного описания](https://github.com/ya-yura/pinkme-krasnodar). Указанные там первичные источники: [карточка 2ГИС](https://2gis.ru/krasnodar/firm/70000001111577745), [запись в Yclients](https://n1954389.yclients.com/) и [Telegram менеджера](https://t.me/pinkme_manager). Повторная прямая проверка из текущей среды недоступна. Расписание, цены и адрес оставлены сервису записи и карточке.

Иллюстрация движения — оригинальная стилизация, не фото студии или тренера. Перед передачей сайту компании нужны сверка данных и согласование.
